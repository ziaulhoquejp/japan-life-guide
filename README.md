# Japan Life Guide

Japan Life Guide is a real-world web platform designed to support foreign residents in Japan with learning, housing, and daily life assistance.

The goal of this project is not just to build a website, but to design and deliver a practical digital system that solves real operational and user problems.

---

## Problem
Foreign residents in Japan often face challenges such as:
- Language barriers in daily life
- Difficulty finding reliable housing information
- Lack of centralized learning resources (e.g., JLPT preparation)
- Fragmented and inconsistent support systems

---

## Solution
This platform addresses these issues by providing:
- Structured JLPT learning support system
- Housing and lifestyle information directory
- AI-assisted guidance (Sakura AI chat)
- Centralized and scalable information architecture
